# AI Research & Coding Agent

An autonomous multi-agent workflow system for research, planning, and AI-powered code generation.

## Features

- Planner Agent
- Research Agent
- Coding Agent
- Reviewer Agent
- Long-context workflow
- Autonomous task execution
- Memory-based iteration
- AI landing page generation

## Workflow

User Request
↓
Planner Agent
↓
Research Agent
↓
Coding Agent
↓
Reviewer Agent
↓
Export Result

## Tech Stack

- Claude Code
- Next.js
- TailwindCSS
- OpenAI API

## Vision

This project explores autonomous AI workflows for research automation and AI-assisted software generation.
